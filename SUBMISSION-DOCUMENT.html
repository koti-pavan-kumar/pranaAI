2. The Solution

PranaAI is a phone-first AI wellness companion that runs 100% on your device — zero internet, zero cloud, zero cost. It uses three breakthrough AI features that have never been combined in a single app:

📷

Camera Breathing Detection

Uses the front camera + TensorFlow.js signal processing with medical-grade bandpass filtering (0.1–0.5 Hz) to detect breathing patterns from chest movement. No wearable needed.

🧠

Real On-Device AI Sentiment

A genuine DistilBERT neural network (758KB ONNX model) runs entirely on the phone's processor via ONNX Runtime Web. Classifies emotions in real-time with no cloud API calls.

🎙️

Voice Mood Journal

Web Speech API captures voice entries in English and Hindi (देवनागरी + Romanized). AI analyzes mood from speech patterns. 100% offline voice recognition.

🌐

Full Offline PWA

Progressive Web App with service worker caching. Works in airplane mode. Installs like a native app. Zero app store fees. Runs on any Android phone with Chrome.

3.1 Camera Breathing Detection Pipeline

Step 1 — Frame Capture: Front camera captures 320×240 frames at 30fps using getUserMedia API
Step 2 — Pixel Analysis: Canvas extracts green channel from center 50% of frame (chest region)
Step 3 — Signal Processing: Bandpass filter (0.1–0.5 Hz) removes noise — this is the same frequency range used in medical respiratory monitors
Step 4 — Phase Detection: Moving average + peak/trough detection classifies breath-in, breath-out, and steady states
Step 5 — Session Analytics: Calculates breathing rate (breaths/min), phase distribution, coherence score, and generates personalized feedback
